# kotlin-calculator-precourse

## 프로젝트 소개

## 주요 기능

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

1. **구분자(쉼표 또는 콜론) 기준 문자열 분리**
2. **커스텀 구분자 기준 문자열 분리**
3. **분리 된 문자열의 숫자 합 반환**
4. **에러 처리**


## 상세 기능

### 사용자 입력

### 구분자 추출 
- **기본 구분자** : 쉼표 또는 콜론를 구분자로 추출 
- **커스텀 구분자** : "//" 와 "\n" 사이의 문자를 구분자로 추출

### 숫자 합 반환 
- **구분자로 숫자 추출**
- **추출한 숫자의 유효성 검사** : 숫자가 아닌 경우, 음수인 경우, (예외 추가)
- **숫자 합 반환** 

## 아키텍처 설계

### MVC 구조 
- model : UserInputString 
- view : inputView, outputView
- controller : Calculator
- utils : 구분자 추출 로직, validation
